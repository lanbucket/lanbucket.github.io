Troubleshooting

Common Issues

If you're sure other devices are on the same network, check these potential issues:

Is LANBucket running?

Make sure that LANBucket is running the most recent version on all devices.

Microsoft Defender Firewall

Microsoft Defender Firewall may block LANBucket from discovering devices. Make sure LANBucket is allowed through on private and public networks. Learn more: Firewall and network protection help

Corporate or Enterprise Networks

Many corporate networks block multicast traffic, which LANBucket requires. This app may not work on workplace networks with strict security policies.

VPN Connections

If you're connected to a VPN, it may prevent local network discovery. Try disconnecting from your VPN.

Virtual Machines and WSL

Running LANBucket inside a virtual machine (Hyper-V, VirtualBox, VMware), WSL, or other virtualized environments may cause network discovery issues due to virtual network adapters. Likewise, if this computer hosts VMs, it may be helpful to disable them.

WiFi Isolation / Guest Networks

Some WiFi networks (especially guest networks) have isolation enabled, which prevents devices from discovering each other. Try using a different network.
