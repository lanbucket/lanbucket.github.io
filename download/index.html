Install via winget

If you prefer command-line installation, you can use winget:

C:\> winget install LANBucket

Offline Installer

Self contained installer that does not require the Microsoft Store, or an internet connection.

  • LANBucket Setup (.exe)

    Simple EXE installer.

  • MSIX bundle (.msixbundle)

    Useful for automated deployments in powershell.

NOTE: The "Microsoft Store" version and the "Offline Installer" version of the app conflict, so only one can be installed on any particular computer.
