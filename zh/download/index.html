通过 winget 安装

如果您更喜欢命令行安装，可以使用 winget：

C:\> winget install LANBucket

离线安装程序

独立安装程序，无需 Microsoft Store，也无需联网。

  • LANBucket 安装程序 (.exe)

    简单的 EXE 安装程序。

  • MSIX 安装包 (.msixbundle)

    适用于通过 PowerShell 进行自动化部署。

注意：“Microsoft Store”版本与“离线安装程序”版本相互冲突，因此每台电脑上只能安装其中一个。

系统要求

操作系统Windows 10 版本 1809，或 Windows 11
处理器x64 或 ARM64
网络局域网连接（WiFi 或以太网）
